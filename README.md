# USB 哨兵

一个只在本机运行的 USB 设备防护小工具。陌生 USB 设备接入 → 分类弹窗报警 + 锁屏 + 写日志；配合系统策略还能拦住陌生 USB 装驱动。

**不联网、不收集数据、零第三方依赖。** 全部是 .NET Framework 自带程序集，源码在 `程序文件\源码\`，可自行审查和编译。

## ⛔ 发布状态：源码版，需自行编译（无预编译 exe）

本仓库**不提供编译好的 exe**。原因：

1. 未签名的 exe 会被 SmartScreen / 杀软误报，安全工具尤其如此；
2. 源码是唯一可信交付物——你自己编一份，才能确认运行的就是你审过的代码。

**编译方式**：装了 .NET Framework 4（Win10/11 自带）后，双击 `程序文件\源码\编译.bat`，产出 `UsbGuard.next.exe`，再双击 `1-装好就能用.bat` 安装。不需要 Visual Studio。

## ⚠ 使用前必读

这不是演示程序，会真的改系统：

- 写入注册表设备策略（未被策略描述的设备禁止安装），并创建 **4 个计划任务**；其中策略守护以 SYSTEM 每 10 分钟校正一次。
- 配置不当**可能误锁键鼠**。救援脚本齐全，但请先读 `使用说明.txt` 的「误锁了键鼠怎么办」和「想卸载时」。
- **只适合个人单机、你自己能物理接触的电脑**。不要装在公司办公机、公用机上。
- **Windows 版本**：系统级驱动拦截依赖 `AllowInstanceIDs`（**Win10 2004 / build 19041+**）与 DeviceInstallation 策略（**Pro / Enterprise / Education / LTSC**）。**家庭版 (Home) 和 19041 之前的 Win10 只保证报警锁屏**，「拦驱动」「U 盘禁执行」不生效或不可用。

## 它能做什么

| 能力 | 说明 |
|---|---|
| 分类报警 | 区分 U盘 / 键鼠(HID) / 其他，HID 提示 BadUSB 注入风险 |
| 立即/持续锁屏 | 陌生设备在位就反复锁，拔出自动停 |
| 白名单 | 设备实例 ID 精确匹配；同一物理设备多个接口归为一个条目 |
| 多杀软扫描 | U 盘插入调用卡巴斯基 `avp.com` 或 Defender `MpCmdRun.exe`，都没有会明确提示 |
| 设备管理窗口 | 查看/删除已信任设备，删除需二次确认 |
| 暂停/维修模式 | 30 分钟 / 2 小时自动恢复；**内存态，重启不持久** |
| 系统级锁定 | 按实例 ID 白名单放行（`AllowInstanceIDs`）；`DenyUnspecified=1` 是全局「未被策略描述的设备禁止安装」，新装的非 USB 设备也可能被拦；已有设备不受影响 |
| 看护与守护 | 主进程挂了 5 分钟内拉起；策略被改 10 分钟内校正 |

## 首次安装

双击 `1-装好就能用.bat` → UAC 点「是」→ 等它跑完 → 右下角蓝色 U 图标。

首次安装会**按你机器上当前插着的设备自动生成白名单**。发布包里的 `usb-whitelist.json` 是空数组 `[]`，安装脚本检测到空名单会按本机设备重建，不继承作者的任何设备。

## 卸载与救援

- **卸载**：双击 `3-撤销加固.bat`。删除 4 个计划任务、撤销全部策略（含 U 盘禁执行）、恢复程序目录权限；白名单与配置保留。
- **误锁键鼠**：`recover-keyboard.bat`、`recover-input.ps1`；`修复-放行此鼠标.bat` 会调用 `-AddDevice` 放行当前设备。都无效用 `3-撤销加固.bat`。
- **最重要的一条限制**：键鼠全被锁住时你**无法双击**这些脚本。真正的最后手段是远程桌面、另一个本地管理员会话、WinRE 离线改注册表，或 PS/2 键盘。**装之前就想好**，笔记本尤其注意（多数没有 PS/2 口）。

## 已知边界（首发版）

技术设计文档是**目标架构**，当前代码是部分落地：

- 系统级策略只做「按实例 ID 放行 + 未描述设备禁装」，**不启用 USB/HID 设备类禁止**（主程序不再写 `DenyDeviceClasses`）——类禁止会误伤蓝牙 HID，且默认评估顺序下 Allow 压不住它。
- 暂停/维修是内存态，**重启不持久**。
- 托盘菜单没有「彻底停止防护」项；真正停止请运行 `3-撤销加固.bat`。
- 家庭版不保证系统级策略生效（见上）。安装脚本会同时检测 Windows build 与版本类型：Home 或低于 19041 时自动跳过系统级拦驱动，只保留报警/锁屏/看护，不会把信任设备也挡住。
- 安装顺序：先注册计划任务、确认「看护」与「实时进程」都成功，最后才写系统策略；关键任务失败会回滚且不写策略，不会留下"策略生效但没主程序"的半装状态。
