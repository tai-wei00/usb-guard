USB 哨兵（v2-rev6 · 2026-11-18）使用说明
====================================

【使用前必读】这是一个会改动 Windows 系统策略的工具
----------------------------------------------------
- 安装后会在注册表开启 USB 设备驱动安装限制，并创建 4 个计划任务（仅策略守护以 SYSTEM 每 10 分钟
  校正，其余为当前用户权限）。它会真的拦住陌生 USB 设备装驱动，不是演示。
- 配置不当可能误锁键鼠、让你暂时无法操作电脑。作者已提供救援脚本，但请先
  看懂「误锁了怎么办」和「想卸载时」两节，再决定要不要装。
- 本工具只适合个人单机、自己能物理接触的电脑。请不要装在公用机、办公机上，
  本包不含预编译 exe——先双击 程序文件\源码\编译.bat 自行生成，再安装。
- 作者对个人使用之外的后果不承担责任；首次安装会自动按你机器当前的设备生成白名单，
  不会继承作者的任何设备。
- 系统版本要求（重要）：系统级「拦驱动」依赖 Win10 2004 / build 19041+ 且
  Pro/Enterprise/Education/LTSC。家庭版(Home)或 build < 19041 的 Win10 只保证
  「报警 + 锁屏 + 看护」，安装脚本会自动跳过系统级拦驱动，不会把信任设备也挡住。

版本：v2-rev6（2026-11-18 更新）
作用：只在本机运行的 USB 设备监控小工具。
陌生设备插入 → 弹窗 + 锁屏 + 记录；配合"USB 锁定"可以拦住陌生 USB 设备装驱动。
程序不联网、不收集任何数据。

怎么装（只需一次）
------------------
1. 把整个文件夹解压到任意位置（建议 D:\USB哨兵，路径别有空格）。
2. 双击「1-装好就能用.bat」，UAC 弹窗点"是"，等它跑完。
   它会自动完成：信任你当前插着的设备 → 设置开机自启 → 创建看护任务 →
   开启 USB 锁定 → 启动哨兵。
   （若目录里存在 UsbGuard.next.exe 新版程序，会先自动替换旧版再继续安装。）
3. 右下角出现蓝色 U 图标 = 正在保护。鼠标悬停图标可查看当前状态。

日常使用
--------
- 插陌生设备：弹窗会标明设备类别并锁屏；不拔掉会一直锁。
  · U盘          → 提示"请勿拷贝/打开其中文件"
  · 键盘/鼠标类   → 提示"警惕 BadUSB 输入注入（伪装键盘自动执行命令）"
  · 其他 USB 设备 → 提示"建议立即拔出，确认来源后再信任"
  确认安全就点「信任此设备」（同一台设备的多个接口会一起信任）。
- 弹窗按钮：信任此设备 / 暂停 30 分钟 / 管理白名单 / 立即锁定；
  25 秒不操作会自动锁屏，直接点右上角关闭也会锁屏（防绕过）。
- 设备管理：右键托盘图标 →「设备管理…」可查看全部已信任设备；
  选中后点「删除选中」并确认，下次该设备插入会重新报警锁屏（删错了重新信任即可）。
- 维修模式：右键托盘 →「维修模式（最长 2 小时）」，期间新设备只记录不报警，
  最长 2 小时后自动恢复完整防护（防止忘记关）。
- 要加新设备（新鼠标 / U 盘 / 键盘等）：先插上设备并等系统识别，再双击「2-添加新设备.bat」。
  脚本会列出当前已插入但还不在信任名单里的设备，逐条核对后输入 Y 确认即可加入信任名单
  并同步系统放行表；输入其他键取消。它不会"临时全面解锁"，系统防护全程没关过。
- 不想这么严：双击「3-撤销加固.bat」。
- 看日志 / 暂停 / 开机自启：右键托盘蓝色 U 图标。日志最新记录在最上面。
- 保存名单或配置时可能弹一次 UAC 授权窗口（程序目录是只读保护，属正常现象）。

U 盘杀毒扫描（多杀软）
----------------------
- 插入 U 盘后自动调用本机已装杀软扫描：默认先找卡巴斯基，找不到再用 Windows Defender。
- 两台都没有时会明确提示"未检测到可用杀毒软件，已跳过自动扫描"（不再静默跳过）。
- 想调整顺序：用记事本（管理员）改 程序文件\usb-guard-config.json 里的
  "scanEngineOrder":["kaspersky","defender"]，两项互换即可；改错会自动回退默认。
- 扫描在后台进行，不影响锁屏防护；超过 10 分钟或中途拔盘会自动中止。
- 右键托盘 →「立即扫描当前U盘」可随时手动扫描。

USB 锁定（v2-rev6 · 2026-11-18）
----------------------------
- 作用范围：开启的是全局策略「未被策略描述的设备禁止安装」(DenyUnspecified=1)，
  再把本机已有设备和你信任的设备逐一写进放行表 (AllowInstanceIDs)。效果是：
  已存在的设备（网卡、虚拟网卡、键鼠、已信任设备）不受影响；之后新装的任何设备，
  无论 USB 还是非 USB（如新蓝牙 HID、新网卡），只要不在放行表里都可能被拦。
  所以加新设备必须先走「2-添加新设备.bat」把它加进放行表。
- 这不是"只拦新插 USB"——它是全局禁装 + 精确放行。作品不含针对网卡的特殊白名单逻辑，
  而是把本机当前全部已装设备一次性纳入放行表作为兜底。
- 家庭版 / build < 19041 的 Windows 不支持 AllowInstanceIDs，安装脚本会跳过整套系统级
  拦驱动策略（只保留报警 + 锁屏 + 看护）。此时不会写 DenyUnspecified，避免误挡设备。
- 加新 USB 设备时用「2-添加新设备.bat」：它把当前设备加入信任名单并同步
  实例白名单，安装脚本 -AddDevice 不会再"临时全面解锁"。

文件说明
--------
1-装好就能用.bat    ← 安装/升级时双击这个
2-添加新设备.bat    ← 要加新设备时双击
3-撤销加固.bat      ← 想撤销系统级限制时双击
使用说明.txt        ← 本文
程序文件\           ← 程序本体，不用管
     UsbGuard.exe          主程序（需先双击 源码\编译.bat 生成，装完自启）
     watchdog.vbs          看护脚本（计划任务用）
     安装.ps1              安装脚本（由 1-装好就能用.bat 调用）
     usb-whitelist.json    信任名单（v2 起为结构化格式：deviceIds/description/
                           category/trustedAt。请勿手工改坏——改坏后程序会进入
                           安全降级：只记录不锁屏，并弹出修复提示）
     usb-guard-config.json 配置（三个开关 + scanEngineOrder 扫描顺序）
     usb-guard.log         日志（运行后生成，在 %LOCALAPPDATA%\USBGuard）
     integrity.json        程序指纹（防篡改）
     源码\                 程序源码（v2 起为 5 个 .cs 文件），可自行审查；
                           双击 源码\编译.bat 可自行编译出 UsbGuard.next.exe

注意
----
- 安装需要管理员权限（UAC 点"是"），这是 Windows 的限制，绕不开。
- USB 锁定下新 USB 设备装不上驱动；用「2-添加新设备.bat」处理即可。
- 本包无预编译 exe；若你对自编译的程序仍有疑虑，请核对源码后再决定是否放行。

升级与回滚
----------
- 升级：把新源码放入 源码\ 并双击 源码\编译.bat 生成 UsbGuard.next.exe，
  再双击「1-装好就能用.bat」即可自动替换（旧版备份为 UsbGuard.pre-v2.bak，
  旧名单备份为 usb-whitelist.json.pre-v2.bak）。
- 回滚必须成组恢复：旧的 UsbGuard.exe + 旧的 安装.ps1 + usb-whitelist.json.pre-v2.bak
  一起还原（旧版主程序读不了新版结构化名单，不能只换 exe）。

怎么关闭 / 临时停止
------------------
- 暂停守卫（托盘右键，30 分钟）/ 维修模式（最长 2 小时）：
  期间陌生设备只记录、不锁屏、不报警，到期自动恢复；都是内存态，
  重启电脑后失效。菜单出现「恢复守卫」时可提前恢复。
- 彻底停止防护（双击「3-撤销加固.bat」，这是卸载，托盘菜单里没有这一项）：
  ⚠ 陌生 USB 设备将可自由安装驱动、U 盘程序可执行，防护完全离线。
  四个计划任务（看护/策略守护/状态提示/实时进程）全部注销删除，退出后不会自动重启；白名单、配置、日志全部保留。
  要恢复防护，重新运行「1-装好就能用.bat」。普通"退出"不是彻底停止（见下）。
- 关于「退出」：点退出后看护任务会在几分钟内自动重启哨兵——这是防误关设计，
  不是关不掉；要真正停止请运行「3-撤销加固.bat」。

误锁了键鼠怎么办（重要，装之前先看）
------------------------------------
按现象选一个，全部需要管理员权限（右键 → 以管理员身份运行）：
- 键盘或鼠标被锁、无法输入 → 双击「recover-keyboard.bat」
- 输入设备整体异常、想全面放行一次 → 双击「recover-input.bat」
- 只是鼠标被挡 → 双击「修复-放行此鼠标.bat」
- 上面都无效 → 双击「3-撤销加固.bat」彻底撤销系统限制，再排查原因。
救援脚本只针对键鼠 / HID 类设备，不会动你的 U 盘白名单；运行后输入即可恢复。
如果是在远程桌面里误锁，先在本地物理机上执行救援脚本。

【最关键的一条】如果键盘和鼠标全被锁住，你没法双击上面任何一个脚本。
真正的最后手段，按可行性排序：
  1. 远程桌面连进来（网络没断的话）——这是最快的；
  2. 另一个本地管理员会话（切换用户）；
  3. WinRE 恢复环境离线改注册表（删掉 DeviceInstall\Restrictions 下的策略键）；
  4. PS/2 接口键盘——注意多数笔记本没有 PS/2 口。
装之前就把这条想清楚。这不是理论风险：策略一旦把键鼠挡在驱动安装之外，
你在本机就失去了恢复输入的能力。

想卸载时
--------
1. 双击「3-撤销加固.bat」（UAC 点"是"）：自动删除全部四个计划任务
   （看护/策略守护/状态提示/实时进程）、开机自启项，并撤销系统级限制；
2. 再删除本文件夹即可。信任名单与配置文件会保留在程序文件目录里，
   不丢数据；想彻底清空就手动删掉这两个 json。
